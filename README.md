# 宏观周期雷达 · Macro Cycle Radar

> 基于《宏观周期感知-研究报告》构建的 AI 自动化宏观周期感知工作台（纯前端）。
> **不预测拐点，只提前感知风向。** —— 霍华德·马克斯："我们永远不知道下一步会去哪，但必须知道自己现在在哪。"

在线地址：**https://259773138.github.io/macro-cycle-radar/**

## ✨ 功能总览

| 模块 | 说明 |
|---|---|
| 📡 总览仪表盘 | 六层仪表盘信号灯、扩散指数与趋势图、美林时钟 + 中国货币×信用时钟、观察/预警/确认三档协议（系统自动建议档位） |
| 📊 指标库 | 内置报告全部核心指标（约 40 项，含看什么/经验含义/局限），可增删改、自定义指标、按层/类型/地区过滤，信号一键切换，自动推导扩散与档位 |
| 🧭 预测日志 | 严格按报告第 5.2 节格式的预测卡片：情景树 + 概率 + 时间窗 + 证伪条件 + 红队论点；到期四维打分 + **Brier 概率校准**看板 |
| 🤖 AI 分析师 | 内置报告方法论系统提示词，流式对话 + 一键动作（生成情景树 / 月度复盘 / 检查证伪条件 / 大白话解释 / 红队挑战），可注入当前仪表盘数据 |
| 📚 知识库 | 两份源文件的结构化精华：方法论、大白话版、月度操作流程 |
| ⚙️ 设置 | 数据导入导出（JSON 备份）、演示数据重置、AI 配置入口 |

## 🔌 AI API 配置（OpenAI 兼容格式 + 魔搭）

1. 打开「AI 分析师」页 → 点「⚙️ 配置」。
2. 选择服务商：
   - **OpenAI**：`https://api.openai.com/v1`
   - **魔搭 ModelScope**：`https://api-inference.modelscope.cn/v1`（需在魔搭平台开通模型推理服务）
   - **自定义**：任意 OpenAI 兼容服务（DeepSeek / Moonshot / Ollama / vLLM 等）
3. 填入 API Key（**仅保存在浏览器 localStorage，不经过任何第三方**）。
4. 点击「从服务器拉取」通过 `GET /models` 获取可用模型列表并选择；若服务器不支持该接口，可直接手动填写模型名（如 `Qwen/Qwen2.5-72B-Instruct`）。

> 无 Key 时除 AI 对话外全部功能正常可用；请使用有额度限制的 Key。

## 🧭 核心方法论速览（来自研究报告）

- **六层仪表盘**：信用与流动性 → 实体领先指标 → 同步指标 → 滞后指标 → 市场与情绪 → 结构脆弱性
- **三档协议**：观察（1 个信号，加密监测）→ 预警（≥3 个独立领先指标同向 2–3 个月，仓位倾斜 1/3~1/2）→ 确认（同步指标跟上，按新周期配置）
- **两套时钟**：美林（增长×通胀，美国约 88%）+ 中国货币×信用版（约 73%）；冲突时信用流动性优先
- **五个技巧**：看序列不看快照、看二阶导（加速度）、看背离（提高监测频率）、看扩散（多少指标同时报警）、先阶段后资产最后才时点
- **可证伪**：每次判断必须写证伪条件与情景树概率；用 Brier 分数做概率校准；四维评分（方向/时机/校准/决策价值）
- **仓位哲学**：倾斜而非一把梭，用仓位管理弥补预测不确定性

## 🛠 本地开发

```bash
npm install
npm run dev        # 开发模式
npm run build      # 构建到 dist/
npm run preview    # 本地预览构建产物
```

技术栈：Vite + React 18 + TypeScript + Zustand + Recharts。数据保存在浏览器 localStorage，可用「设置」页导出/导入 JSON 备份。

## 🚀 部署（GitHub Pages）

- `main` 分支保存源码；每次 push 自动触发 `.github/workflows/deploy.yml`，构建后发布到 `gh-pages` 分支。
- Pages 源已设为 `gh-pages` 分支根目录。若迁移账号/仓库，需在仓库 Settings → Pages 重新选择 `gh-pages` 分支。

## 📂 目录结构

```
src/
  lib/        # 类型定义、内置指标元数据、状态管理、AI 封装、提示词
  pages/      # 六个页面：Dashboard / Indicators / Predictions / Assistant / Knowledge / Settings
  components/ # 通用徽章组件
```
